# Hermes profile distribution stub

This repository doubles as the temporary profile source. Only SOUL.md, skills/, and distribution.yaml are distribution-owned.
Working context, lessons, experiments, and policy source are deliberately excluded from profile updates.

With GitHub authentication configured, install using:

    hermes profile install https://github.com/Metta-AI/rohit-optimizer

Confirm the installed Hermes version supports distributions before running the command.
Installation does not authenticate GitHub/Softmax, clone workspaces, or automatically run research.
The IDE backend owns provisioning, credential delivery, and selecting the installed profile when opening the session.
Workspace clones are separate from the profile directory and must preserve existing edits.

This stub uses the seed's documented lifecycle checklist; native hooks and hosted installation remain unverified.
A coworker's distribution will replace the stub without replacing the research or policy repositories.
